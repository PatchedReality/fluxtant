# Fluxtant

  Managed hosting for Metaverse Servers. Spin up persistent virtual worlds grounded in real-world geography, without
  running the infrastructure underneath.

  Fluxtant is a hosted platform for running Metaverse Servers and the spatial fabrics that live inside them. You sign
  up, point it at a geography (a campus, a neighborhood, a city), and we generate and run the world. Built for
  independent 3D creators and small studios who would rather build virtual spaces than babysit Docker containers.
  
  We're part of the [Patched Reality](https://patchedreality.com) ecosystem. If you've shipped on RP1 or know it from
  elsewhere, Fluxtant is the managed path: same runtime, no servers to maintain.
